# Prime Cloud 3D Website V3

A premium, mobile-responsive promotional website for Prime Cloud.

## Included
- 3D animated cloud/server core using Three.js
- Premium dark glass + neon visual style
- Minecraft / VPS / Special plan cards marked Coming Soon
- Prime Cloud Discord invite: https://discord.gg/SHGztEuDg
- Community screenshot showcase from the provided references
- Scroll reveal, hover effects, parallax tilt and responsive layout

## Publish
Upload the whole folder to GitHub Pages, Netlify, Vercel, or Cloudflare Pages.

No build step is required. The 3D renderer is loaded from the Three.js CDN.
